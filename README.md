
# Kuwait Driving Simulator

A realistic 3D driving simulator inspired by the streets of Kuwait.

## Game Engine
Unreal Engine 5

## Platform
iOS (iPhone)

## Main Features
- Realistic sports car driving
- Kuwait-inspired city environment
- Third-person camera
- First-person cockpit camera
- Touchscreen driving controls
- Realistic vehicle physics
- Speedometer
- Engine sounds
- High-quality graphics

## Development Roadmap
1. Project setup
2. Sports car implementation
3. Vehicle physics
4. Camera system
5. Kuwait city environment
6. Mobile controls
7. Optimization for iPhone
8. iOS build and testing
